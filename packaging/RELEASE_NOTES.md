## 🎁 Secret Santa

Draws names for Secret Santa and emails each person only the name they drew. Spouses never draw each other.
Use test mode to preview the pairings before sending anything.

### Download
| Your computer | File |
|---|---|
| Windows 10 / 11 | **secret-santa-windows-x64.zip** |
| Mac with Apple Silicon (M1, M2, M3, M4…) | **secret-santa-macos-apple-silicon.zip** |
| Mac with an Intel chip | **secret-santa-macos-intel.zip** |
| Linux / Ubuntu (64-bit) | **secret-santa-linux-x64.tar.gz** |

Not sure which Mac you have? Click  → **About This Mac**. "Chip: Apple…" means Apple Silicon. "Processor: Intel…" means Intel.

### How to use
1. Download and unzip the file for your computer.
2. Double-click **secret-santa**. The form opens in your web browser.
3. Add everyone's name, email and spouse (optional). Try **Test mode** first, then **Draw & send emails**.

The first time you open it, Windows or macOS will warn that the app isn't from a known developer.
This is normal for free apps that aren't code-signed. `HOW-TO-RUN.txt` in the download shows how to open it anyway.
It also lists the Gmail settings you'll need.
